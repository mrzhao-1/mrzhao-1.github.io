本文档整理在大多数 Markdown 平台中都能使用的语法。  
常见平台包括：GitHub、GitLab、Obsidian、Typora、Notion、语雀、掘金、CSDN、Hugo、Hexo、VuePress 等。

> 注意：不同平台对扩展语法支持程度不同，表格、任务列表、数学公式、HTML 等属于常见扩展，但并非 100% 通用。

---

## 1. 标题

```markdown
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
##### 五级标题
###### 六级标题
```

---

## 2. 段落与换行

```markdown
这是第一段。

这是第二段。
```

如果需要在段落内强制换行，多数平台支持行尾加两个空格：

```markdown
第一行  
第二行
```

部分平台也支持直接使用 `<br>`：

```markdown
第一行<br>
第二行
```

---

## 3. 强调

```markdown
**加粗**
*斜体*
***加粗斜体***
~~删除线~~
`行内代码`
```

---

## 4. 列表

### 无序列表

```markdown
- 项目一
- 项目二
  - 子项目
  - 子项目
```

### 有序列表

```markdown
1. 第一项
2. 第二项
3. 第三项
```

### 任务列表

```markdown
- [x] 已完成
- [ ] 未完成
```

任务列表在 GitHub、GitLab、Obsidian、Typora 等平台支持较好，部分博客平台可能不支持。

---

## 5. 链接

```markdown
[链接文字](https://example.com)
[链接文字](https://example.com "标题")
```

自动链接：

```markdown
<https://example.com>
```

---

## 6. 图片

```markdown
![替代文字](https://example.com/image.png)
![替代文字](https://example.com/image.png "图片标题")
```

建议使用完整 URL 或相对路径。  
如果跨平台发布，最好使用可公开访问的图片地址。

---

## 7. 引用块

```markdown
> 这是一段引用。
>
> 这是引用中的第二段。
```

嵌套引用：

```markdown
> 第一层
>> 第二层
```

## 8. 代码块

行内代码：

````
```
`code`
```
````

围栏代码块：

````
```java
public class Hello {
    public static void main(String[] args) {
        System.out.println("Hello");
    }
}
```
````

或者不指定语言：

````
```
纯文本代码块
```
````

---

## 9. 代码块中显示```

### （1）嵌套使用反引号（最常用）

规律：
```
| 内层连续反引号  | 外层需要     |
| :--- | :--: | ---: |
| 3 个 ```      | 4 个 ````   |	
| 4 个 ````     | 5 个 `````  |
| 5 个 `````    | 6 个 `````` |	
```
总之：外层永远比内层多一个。

### （2）用波浪线 ~~~ 代替反引号

内层是反引号，外层用波浪线，两者不冲突：
````
~~~markdown
```java
public class Hello {}
```
~~~
````

### （3）缩进四个空格

传统 Markdown 写法，缩进四个空格就是代码块：

````
    ```java
    public class Hello {}
````

## 10. 表格

```
| 姓名 | 年龄 | 城市 |
| :--- | :--: | ---: |
| 张三 | 20 | 北京 |
| 李四 | 25 | 上海 |
```

对齐方式：

```
:--- 左对齐
:---: 居中对齐
---: 右对齐
```
表格在 GitHub、GitLab、Obsidian、Typora、Hugo、Hexo、VuePress 等平台通常支持。

## 12. 转义

```
\*不是斜体\*

```

## 13. 数学公式
数学公式语法通常使用 LaTeX，但是否渲染取决于平台。
行内公式：
```
当 $a \neq 0$ 时，方程 $ax^2 + bx + c = 0$ 有两个解。
```
块级公式：

```
$$
E = mc^2
$$
```
支持情况：
Obsidian、Typora、Notion、语雀、部分博客平台支持。
GitHub 部分支持。
很多平台需要手动开启 MathJax 或 KaTeX。

---

## 14. HTML 基础标签

部分平台允许在 Markdown 中嵌入 HTML：
```
<div align="center">居中内容</div>
<br>
<strong>加粗</strong>
<em>斜体</em>
```
支持情况因平台而异。

有些平台会过滤 HTML，有些平台会原样显示。

| 功能                   |  通用性 | 说明 |
| :---                   | :--: | ---: |
| 标题、列表、链接、图片 | 高    | 标准 Markdown |
| 删除线、任务列表、表格 | 中高  | 属于 GFM 等扩展 |
| 数学公式               | 中	 | 需要平台支持或插件 |
| HTML	                 | 中	 | 部分平台过滤 |
| 脚注	                 | 中	 | 部分平台支持 |
| 定义列表	             | 低	 | 依赖解析器 |

---

- 链接

- 图片

- 引用

- 代码块

- 表格

- 水平分割线

- 转义

- 数学公式语法

- 基础 HTML
