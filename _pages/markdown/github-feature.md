## 一、github page 的评论区功能

1. 打开仓库设置，开启讨论区：仓库页面 → Settings → General → 找到 Features → 勾上 Discussions。
2. 装 giscus：打开 https://github.com/apps/giscus → 点 Install → 选择 mrzhao-1.github.io 这个仓库 → 授权。
3. 拿配置 ID：打开 https://giscus.app → 填仓库名 mrzhao-1/mrzhao-1.github.io → 页面下方会生成一串配置（有 4 个     ID 和一个分类名）→ 把这些发给我。
